# Answer-support development sources

The public development run uses the complete **SQuAD 2.0 development set**, from Rajpurkar, Jia and Liang, *Know What You Don't Know: Unanswerable Questions for SQuAD* (2018), via the [official SQuAD site](https://rajpurkar.github.io/SQuAD-explorer/). Dataset: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Pinned `dataset/dev-v2.0.json` Git blob: `c6fa1a89a12c90b7fbfa8f6fb437cfff27af41ca` in `rajpurkar/SQuAD-explorer`.

`public-outcomes.jsonl.gz` and the public accuracy results in `public-results.json` are derived evaluation outputs, provided under **CC BY-SA 4.0**. The compressed file retains every question ID, literal prediction, status, best candidate, character/UTF-8 anchors, window count, raw null-minus-span difference and independent EM/F1 outcome. Repeated constant source identifiers and source hashes are reconstructable from the pinned input paragraphs. These are model outputs and transformations, not original human answers or clinical evidence. Original public paragraphs and gold annotations are not copied into this repository. Nothing here implies endorsement by the dataset authors.

The [official evaluation source](https://github.com/rajpurkar/SQuAD-explorer/blob/master/evaluate-v2.0.py) is pinned by Git blob `21f52c179c8c6547ae5999215f8afd36038f20ca`. Its complete source was inspected before import/execution. Official fixed-prediction EM/F1 is compared with a separate implementation for every question and all aggregate groups. No probability file, best-threshold search or hidden test data is used. The downloaded evaluator remains outside the repository; its source receipt is retained.

The fixed model is [deepset/minilm-uncased-squad2](https://huggingface.co/deepset/minilm-uncased-squad2/tree/934656cdda79824eabf503ed56e15c01ddbdbe3f), revision `934656cdda79824eabf503ed56e15c01ddbdbe3f`, published by deepset under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Only the pinned safetensors, configuration and tokenizer inputs are downloaded. No weights or converted model are distributed in Lumen. Its model card already uses SQuAD 2 development evaluation; this run is **replication/development**, not unseen generalization.

The 32 Lumen questions, source texts, frozen literal-answer aliases and eight additional stress cases are self-authored synthetic diagnostics. The 32 questions are evaluated under both previously frozen source-selection pipelines; this produces 64 cases plus eight provided-context cases. These labels are not independently established clinical truth. Strict synthetic comparison preserves case, operators, units, negation and complete compound answers; public benchmark normalization is never used for that comparison.
