## Evidence and design

Number interpretation has three explicit choices: Dot, Comma, or Keep wording only. The last choice preserves numeric-looking wording without interpreting or plotting it. Comparison selection persists across test/context groups for literal review; differing groups never enable arithmetic. Saved comparisons carry compatible optional typed source/value metadata beside their portable text. Native details show whether each original still matches, changed, was removed, or needs source review. Editing the saved comparison text keeps the earlier capture separately labelled and withholds its earlier structured arithmetic from new assistant reference text. Old documents without this optional metadata remain unchanged.

The implementation checks exact subtraction with signed decimal digits as well as Foundation's status. A successful status alone can hide scale-alignment loss when operands differ greatly. If the exact difference cannot be represented, arithmetic is withheld. Immutable point identities, validated collection days and test groups are prepared once off the main actor; the full bounded selection can retain 2,560 reviewed results without a plotted prefix.

Both individual source matching and report-level source anchors require exact UTF-8 spelling. Canonically equivalent Unicode strings with different original bytes do not establish a literal excerpt match. Existing generated references and fingerprints remain unchanged.

Plot selection uses an explicit tap through Apple's ChartProxy selection API. The nearest recorded collection day remains selected for Show selected day until cleared or the interpretation/group/date window changes. The selected-day list remains a separate explicit filter; Show all results restores the complete group. [Apple's Charts interaction session](https://developer.apple.com/videos/play/wwdc2023/10037/) documents custom selection gestures through chartGesture/selectXValue. NativeR7 verifies the persistent tap, selected-day filter and return to the complete group; its source boundary and later display-only refinements are recorded in the native evidence.

The chart's date ticks label the actual first and last plotted collection days. At accessibility sizes, complete day/month labels use two lines and the chart grows to440 points; type size is not reduced. This changes axis labels only, never the plotted result set. Tick labels and axis titles use the established secondary ink. NativeR9/SmallR2 and the final NativeR10 presentation capture verify the refinement within their recorded source boundaries.

Keep the established daylight-observatory direction and native controls. No new concept/icon/paywall/store/motion scope. Use the same independent critic for actual light/dark/XXXL/compact simulator screens, with at least two rounds and all concrete defects closed. Verify parser precision, dates/time zones, source freshness, grouping, duplicates, missing/qualified values, numerical overflow and source-checked snapshot saving, plus real encrypted/readable backup round trips. ## Source informing the comparison boundary

[MedlinePlus: How to Understand Your Lab Results](https://medlineplus.gov/lab-tests/how-to-understand-your-lab-results/) (read31 October2026) explains that methods and reference ranges vary between laboratories, units differ, and clinical meaning depends on wider context. This supports preserving each report's own fields and requiring matching laboratory/unit context; it does not validate Lumen or establish clinical comparability merely because strings match. Clinical interpretation, comprehensive coding/UCUM normalization, physical-device/VoiceOver validation and provider quality remain separate open work.
